# Демо-лендинги для портфолио

Сайт — портфолио на GitHub Pages: `index.html` (главная, тёмная, графит и охра) и папки `demo-<ниша>/index.html` — по одному вымышленному бизнесу в каждой. Демо показывают будущему клиенту, как Арсений думает о его посетителях, поэтому каждое должно **делать** что-то полезное, а не только выглядеть.

## 1. Сначала идея, потом код

Перед кодом реши и коротко скажи пользователю три вещи:

1. **Главное действие посетителя** этой ниши. Кофейня — занять стол, маникюр — выбрать цвет и записаться, автосервис — узнать цену, фитнес — попасть на занятие.
2. **Живой инструмент на первом экране**, который это действие выполняет: план зала с бронью, подбор лака на пальцах, калькулятор цены, расписание с фильтрами. Это сердце демо — на нём строится всё остальное, и он заканчивается заявкой, куда уже подставлен выбор.
3. **Характер**: название в кавычках-ёлочках с игрой слов («Кафель», «Гайка», «Палитра», «Поток», «Чуб»), палитра из 2–3 цветов + акцент, пара шрифтов. Не повторяй уже занятые:

| Демо | Палитра | Шрифты | Инструмент |
|---|---|---|---|
| demo-coffee «Кафель» | кобальтовая плитка | Unbounded + Golos Text | бронь на плане зала |
| demo-barber «Чуб» | тема Telegram | системный | Mini App записи |
| demo-nails «Палитра» | лаковая вишня, пудра | Prata + Manrope | подбор цвета на руке |
| demo-fitness «Поток» | шалфей, хвоя, фиолетовый | Rubik | расписание недели |
| demo-autoservice «Гайка» | графит, сигнальный оранжевый | Oswald + PT Sans | калькулятор цены |
| главная | графит, охра, жидкое стекло | Geologica + Onest | живые демо в iframe |

Избегай безликого «AI-лендинга»: фиолетово-синих градиентов на белом, Inter, одинаковых карточек с иконками, «Почему выбирают нас». У каждого демо свой силуэт первого экрана.

## 2. Как устроен файл

Один самодостаточный `index.html`: стили в `<style>`, скрипт в `<script>` в конце, без сборки и библиотек. Шаблон — `demo-fitness/index.html` (самый короткий), сверяйся с ним.

- `<html lang="ru">`, `title` = название, `meta description` начинается с «Демо-лендинг …: <что умеет инструмент>.»
- Шрифты — Google Fonts с `preconnect` и `display=swap`, только нужные начертания.
- Первая строка CSS — комментарий-замысел: `/* Шалфей и хвоя с электрическим фиолетовым; главное на странице — живое расписание недели */`. Разделы CSS подписаны по-русски: `/* Расписание */`, `/* Разделы */`.
- Цвета — переменные в `:root`, плюс `--ease: cubic-bezier(.16, 1, .3, 1)`.
- Общие основы: `box-sizing`, `.wrap` с `max-width ~1200px` и отступами `max(clamp(16px, 4vw, 48px), env(safe-area-inset-left))`, `text-wrap: balance` у заголовков, `font-variant-numeric: tabular-nums` у цен и времени, свои `::selection` и `:focus-visible` в цвет акцента.
- Размеры шрифтов и отступов — `clamp()`; сетки — `minmax(0, 1fr)`, чтобы ничего не распирало.
- Адаптив: `@media (max-width: 960px)` — в одну колонку, `680px` — прячем nav. Широкие таблицы и ленты на телефоне скроллятся вбок **внутри себя**, страница — никогда.
- `@media (prefers-reduced-motion: reduce)` — обязательно; анимации при прокрутке в нём превращаются в обычную статичную вёрстку.
- Сверху `.demo-bar`: «Демо-проект для портфолио: … вымышлены, запись никуда не отправляется.» В футере: ««Название» — демо-проект для портфолио. … вымышлены. Фото: Unsplash.»

### Фото

Unsplash по прямой ссылке с обрезкой под место: `https://images.unsplash.com/photo-<id>?auto=format&fit=crop&w=700&h=520&q=75`. Всегда `width`/`height`, осмысленный русский `alt`, `loading="lazy"` всё ниже первого экрана. ID бери только проверенные: скрипт проверки ниже ловит битые. Если сеть не пускает к Unsplash — нарисуй SVG-иллюстрацию, не оставляй пустых рамок.

### Скрипт

- Обёртка `(() => { ... })();`, `const $ = (s) => document.querySelector(s);`.
- Данные — константы вверху (`CLASSES`, `KINDS`, цены) с комментарием о формате; разметка собирается из них в `render()`.
- Даты считаются от сегодняшнего дня, прошедшее время недоступно — демо не должно устаревать.
- Русские числительные через `plural(n, 'место', 'места', 'мест')`.
- Состояние кнопок — через `aria-pressed`, `aria-disabled`, `hidden`; стили цепляются к ним же.
- Форма: `novalidate`, своя проверка имени (≥ 2 символа) и телефона (10–11 цифр), понятная ошибка в `aria-live="polite"`, фокус на поле с ошибкой, `aria-invalid`. Отправка — кнопка «Отправляем…» и через ~600 мс экран «Готово» с тем, что выбрано, и строкой: «Это демо: заявка никуда не ушла. В рабочей версии она пришла бы администратору в Telegram.»
- Всё, что ввёл пользователь, вставляется в HTML только через `esc()`.
- Плавная прокрутка учитывает `prefers-reduced-motion`.

### Telegram Mini App

Ориентир — `demo-barber/`. Подключай `telegram-web-app.js`, бери цвета из `--tg-theme-*` (своя палитра — только запасная вне Telegram), используй `MainButton`/`BackButton`, имя из `initDataUnsafe.user`; вне Telegram показывай свою нижнюю кнопку. Данные демо — в `localStorage`, обёрнутом в try/catch.

## 3. Тексты

Пиши как живой администратор этого места, на «вы», коротко и конкретно: цифры, время, что взять с собой. Цены правдоподобные для Петербурга, с неразрывным пробелом: `5 600 ₽`. Адрес и телефон — явные заглушки с подписью «адрес вымышлен» / «номер-заглушка». Без «качественно», «индивидуальный подход», «команда профессионалов».

## 4. Проверка — обязательно перед коммитом

```bash
node .claude/skills/landing/scripts/check.mjs demo-<ниша>
```

Скрипт поднимает локальный сервер, открывает страницу в Chromium на 390 px и 1280 px, прокручивает до конца и падает, если есть ошибки JS, страница едет вбок (и называет виновника), битые картинки, `img` без `alt`, не один `h1`, нет description. Мелкие для пальца кнопки выводит предупреждением. Скриншоты целиком — в `.shots/`.

Потом **посмотри скриншоты сам** (Read на png): скрипт не заметит некрасивое — налезший текст, пустоту, нечитаемый контраст. Пройди главный сценарий руками через Playwright: выбрать → заявка подставилась → ошибка формы → «Готово». Исправь и прогони снова, пока не станет ✓.

## 5. Добавить работу на главную

1. Карточка 960×600: `node .claude/skills/landing/scripts/check.mjs demo-<ниша> --card` — сохранит `img/<ниша>.jpg` (первый экран на 1440 px). Посмотри её.
2. В `index.html`, раздел `#works`, блок `.more` — добавь `article.mini-case` по образцу соседних: картинка-ссылка, `h4` с названием, одна фраза о том, **что делает посетитель**, кнопки «Открыть сайт» и «Код» (ссылка на `tree/main/demo-<ниша>`).
3. Прогони проверку и для главной: `node .claude/skills/landing/scripts/check.mjs .`

## 6. Коммит

Сообщение по-русски, в стиле истории: что видно пользователю, а не что поменялось в коде. Пример: «Гайка: закреплённая шапка, гайка крутится и растёт при прокрутке». Новое демо: «Демо-лендинг <ниши> «Название»». Один коммит — одна законченная мысль.
